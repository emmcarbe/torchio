This is a demo site for an experiment in progress. Information is available in the README, and the project principles are here.

Demo editions

  • Odyssey: Homer, Greek text (Perseus Digital Library, CC BY-SA 4.0)
  • Vincent van Gogh, the letters: a sample of 30 letters (Van Gogh Museum and Huygens ING, CC BY-NC-SA 4.0)
  • Bellum Alexandrinum: ed. Cynthia Damon et al., Digital Latin Library (CC BY-SA 4.0; beta version pending SCS peer review; temporary test sample)
  • Romualdus Salernitanus, Chronicon: ed. Paolo Monella, ALIM Project (GPL 3.0), offered by the editor as a test case
  • Ursus Beneventanus, Adbreviatio artis grammaticae: ed. Paolo Monella, ALIM Project (GPL 2.0), offered by the editor as a test case; graphematic transcription with reading and diplomatic views
  • Specimen: a constructed example showing apparatus, witnesses, transcription levels, indices and map (public-domain base text, CC0 encoding; interface in Italian, as a bilingual demonstration)

Try Torchio yourself

The press, in the browser: choose the files of a TEI P5 edition (the ODD too, if you have one) and it is pressed into a static site on your machine. Compose it in the panel, add your own pages in Markdown, download the result. Nothing is uploaded anywhere.

Desiderata

Wishes and requests are collected in DESIDERATA.md. If you are logged in to GitHub, this link opens the file for editing: write your line in Markdown and submit, and GitHub will propose it as a pull request.
